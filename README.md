# MySQL-Business-analysis
运用Excel和MySQL对印度电子商务数据集进行销售额的业务分析
数据涵盖2023–2025年度10万笔订单、2.5万客户、550条产品、支付、发货、退货、评价及营销活动。


指标：销售额=销售数量×销售单价

## 具体流程

### 1.查看销售额的变化趋势

通过代码发现销售额环比下降最大的月份:2025年1月的54190915.9卢比到2025年2月42519518.4卢比，销售额下降了11671397.5卢比，环比下降21.54%。
销售额环比上升最大的月份：2023年1月的8,838,803.65卢比到2023年2月的19,718,359.40卢比，销售额上升了10879555.75卢比,环比增长123.08%，但是属于业务起步阶段的正常跳升，参考意义有限。
销售额环比值增长最大的月份:2025年9月的67311955.05卢比到2025年10月的111759809.10卢比，销售额上升了44,447,854.05卢比，环比增长66.03%。

本文主要选取销售额下降最大的月份进行业务数据分析

### 2.对渠道与销售额进行交叉分析

通过交叉分析进一步得到Organic Search、Social Media - Facebook、Affiliate、Email Marketing、Paid Search五个渠道的销售额下降9563481.35卢比，占销售额总体下降的81.9%。

### 3.对销售额指标拆分成子指标进行进一步分析

进一步拆分销售额的下降是销售数量的下降还是销售单价的下降，由于在产品表中产品的价格是固定的，所以销售额的下降大概率是销售数量下降导致的。接下来通过数据分析进行验证。

通过数据查询发现2月份的销售数量比1月份减少1610件，但同时发现有折扣政策的存在，所以折扣政策也可能侵蚀了单价进而导致销售额下降的重要原因。但由于订单包含多种商品且折扣各异，逐商品拆分计算量较大。本文在总量层面进行量价分解，以加权平均折后单价代表整体价格水平，将销售额变化拆分为销量效应和价格效应。该方法的局限在于无法进一步区分“单品折扣变化”与“商品结构变化”，但不影响对“销量 vs 价格”主因的判断。

### 4.判断价格效应和销量效应对销售额的影响

指标:价格效应 = (实际价格 - 计划价格) × 实际销量
     销量效应 = (实际销量 - 计划销量) × 计划价格

通过计算，销量导致的销售额下降7086389.08卢比，折扣侵蚀单价导致的销售额下降了2477092.27卢比。销售数量的下降是导致销售额下降的主要因素，占总下降比例的74.1%，所以接下来对销售数量的下降原因进一步拆分。

另外，本文已在总量层面量化了折扣对销售额的侵蚀效应，但无法进一步给出“折扣应如何调整”的具体建议。原因一是由于数据中不存在“无折扣”情况下的销量和销售额。二是平台商品数量繁多，各商品折扣率、销量、单价差异较大，折扣对销售额的影响在不同商品间不可直接比较，无法形成统一的折扣调整策略。因此，本文对折扣的分析止于“量化其对单价的侵蚀贡献”，不进一步延伸到折扣策略优化。

### 5.分析销量下降的原因

首先判断是订单数下降导致的销售数量的下降还是每笔订单下单量的减少导致的总的销售数量的下降。

通过分析，订单数由1月的1272个下降到2月的1034个，下降了18.7%，而每单订单下单量仅有1月份的6.01到2月的5.84，仅下降了2.9%，而销量由7645下降到6035，下降了21.1%。所以销量的下降主要是由于订单数的下降导致的。

### 6.对订单数的下降进行进一步分析

维度：用户层次、营销活动角度、渠道、退款情况

用户角度:1月份新用户数563位，新用户订单数89单，新用户转化率15.8%，老用户订单数1183单。2月份新用户数482位，新用户订单数47单，新用户转化率9.75%，老用户订单数987单。老用户流失数301位，其中高净值用户88单。

营销活动：2025年1月和2月的仅有Affiliate、Paid Search、Email Marketing有营销活动，且ROI基本为正，只有Paid Search在1月份的营销活动roi有轻微亏损，为-0.136。

退款状态：1月总退货111单，订单失败45单,订单取消119单；2月总退货74单，订单失败39单，订单取消92单。

## 结论

从用户角度看，高净值流失用户在2025年1月共贡献88单、251.45万卢比销售额，占五渠道1月销售额约7.5%，相当于五渠道2月销售额下降的26.3%。在老客订单减少的196单中，高净值流失贡献88单，占44.9%。分渠道看，Email Marketing高净值流失销售额最高（73.0万），AOV高达6.64万，单客户价值最大；Organic Search订单最多（33单），绝对损失大；Affiliate仅9单却贡献49.3万，AOV 5.48万，是高客单流失渠道；Paid Search和Social Media订单数不少，但客单价相对较低。总体看，高净值流失是老客复购收缩的核心子集，是2月销售额下降的重要直接来源。营销活动ROI整体健康，不是订单数下降的直接主因；退款、失败、取消绝对量下降，也不是直接原因，但订单失败率略升，需关注滞后复购影响。

## 业务调整建议

### 1.高净值流失客户一对一召回

Email Marketing：专属邮件/短信，VIP权益，新品优先购，客服回访。

Affiliate：检查联盟佣金/优惠券变化，专属客服召回，高客单券。

Organic Search：复购提醒，品类补货通知，会员积分唤醒。

Paid Search：再营销广告，关键词优化，落地页专属优惠。

Social Media：更新广告素材，召回活动，测试新促销。

### 2.老客分层召回与复购提升

对301位老客按渠道、客户细分、最后购买品类、退货历史分层。
高价值+无退货：专属折扣、会员积分、提前购。
高价值+有退货：客服回访，解决体验问题，再给补偿券。
普通老客：满减券、品类券、邮件/短信召回。

指标：唤醒率、复购率、召回成本、ROI。

### 3.新客拉新与首购转化

加大SEO(搜索引擎优化)、内容营销、Paid Search、Social投放；优化新客首单券、免邮。同时优化落地页、商品详情、信任元素；对注册未购用户做7天/14天唤醒。

指标：新客注册数、首购率、CAC、首单AOV。

### 4.分渠道策略调整
| 渠道 | 现状诊断 | 优化策略 |
| ---- | ---- | ---- |
| Email Marketing | 高净值流失销售额最高，AOV最高 | 分群发送，高价值客户专属选品，减少全场深折 |
| Affiliate | 高客单流失，订单降幅大 | 审查联盟质量，限制优惠券滥用，专属召回 |
| Organic Search | 绝对损失最大，订单减少81单 | 加强SEO内容、品牌词、老客复购 |
| Paid Search | 纯订单数问题，1月ROI轻微亏损 | 优化关键词、落地页、再营销，不盲目砍预算 |
| Social Media | 量价双杀，广告可能疲劳 | 更新素材、受众，测试新促销 |

### 5.AOV与折扣优化
每单件数下降 → 捆绑销售、满件折、搭配购、补货提醒。

件均价下降 → 检查折扣区间，限制高折扣券滥用；按客户分层给折扣。

品类结构变化 → 分析高价品类销量占比；对高价值客户推高价新品、套装。

指标：AOV、每单件数、件均价、折扣率、高价品类销售占比。
